The rules under all of it

No screenshots
Text only. Never keystrokes or clicks. On-screen capture reads the accessibility tree and stores no image.
Local by default
The default summariser runs no model. A cloud tier is opt-in, and every send is appended to egress.log.
Per-source consent
Each source is a separate switch. On-screen text is off until you turn it on.
Clearing is real
myday clear removes the notes and the raw events and derived caches behind them.
One machine
No sync. The record lives on the Mac that made it, by design.

Ships two ways off the same store: a menu-bar app with a bundled Node runtime, or npm install -g @abhitsian/myday. macOS, Apple Silicon.
